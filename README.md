# Python-Simple-Calculator

A simple calculator built with Python as part of my programming learning journey.

This project performs basic arithmetic operations such as addition, subtraction, multiplication, and division. While it may be a small project, it helped me put fundamental programming concepts into practice and gain hands-on experience building something from scratch.


## About the Project

When learning to code, one of the best ways to improve is by building projects. This calculator was created to strengthen my understanding of Python fundamentals, including user input, conditional statements, functions, and program flow.

The goal was to create a simple, functional application while focusing on writing clean, readable code and developing problem-solving skills.


## Features

- Basic arithmetic operations
- Easy-to-use interface
- Beginner-friendly code structure
- Lightweight and fast


## What I Learned

Building this project helped me practice:

- Working with variables and data types
- Taking and validating user input
- Using conditional statements (if, elif, else)
- Creating reusable functions
- Handling errors and unexpected inputs
- Organizing code for better readability


## Tech Stack

- Python 3
- Tkinter
- ttk


## Running the Project

Clone the repository:
- git clone [https://github.com/Purvanshu2/Python-Simple-Calculator.git](https://github.com/Purvanshu2/Python-Simple-Calculator.git)

Move into the project directory:
- cd Python-Simple-Calculator

Run the program:
- python calculator.py
